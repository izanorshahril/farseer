# Farseer Berd Home Prototype

## Scope and mode

Static interactive prototype for `.scratch/farseer/prototypes/berd-home/index.html`.
Mode: Operate.
This is an approval surface and does not replace `ui/` yet.

## Audience, job, and action

A local fleet operator opens Farseer to reorient after an interruption.
Within five seconds they should see what needs attention, what is active, which project is in context, and where to resume.
The primary action is starting or resuming work through the home composer.

## Content and constraints

Use Farseer's real nouns and capabilities without inventing commercial claims.
Demonstration runs and projects are synthetic preview data and must be visibly labeled.
Preserve top-manager routing, direct run controls, project context, quota truth, and the distinction between cells and runners.
Chat history and the full conversation screen are deferred.

## Direction

Close homage to Berd's current home: a quiet persistent sidebar, compact top bar, pale dotted freeform canvas, soft neutral panels, rounded global composer, Inter-like workhorse typography, and restrained state color.
Translate Berd's single-agent pins into Farseer's fleet objects rather than copying its product model.
The memorable first viewport is a large local clock and greeting surrounded by a few freely arranged operational pins, with the composer floating at the bottom center.

## Unresolved

The final chat composition will be designed separately with Claude Code desktop as a second reference.
Whether this prototype replaces the production canvas remains an approval decision after review.
